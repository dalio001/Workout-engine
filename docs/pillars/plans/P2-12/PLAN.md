# P2-12 timed sets (written by DeepSeek V4.1 Flash in plan mode, saved by the supervisor 2026-10-17)


**Today.** `EXERCISE_TYPES` has `'duration'` and 5 catalogue rows use it (ex60 Plank, ex64 Mountain Climber, ex66 Side Plank, ex94 Farmer Carry, ex95 Battle Rope), but logging ignores it: `renderActiveWorkout()` always renders the `KG`/`REPS` inputs (`set-w-`/`set-r-`), `getRepsError`/`isSetTickable` require reps 1..1000, `toggleSetDone` refuses the ✓, `doFinishSave`/`countDoneValidSets` filter `Number(s.reps) > 0`, so a plank set is untickable and a plank-only workout cannot be saved. `metricCountingSets` skips reps-less sets → duration is invisible to `exerciseRecords`/`exerciseSessions`/`renderProfileRecords`. `normalizeRoutineItem` has no duration target, and `saveHistEdit` re-maps sets to `{type,weight,reps,done}` (would silently drop a time). There is no per-set stopwatch; only `restDeadline`/`startRestTimer` exists.

**Data shape (no schema bump, stays `SCHEMA_VERSION = 2`).** A duration set = `{ type:'N'|'W'|'D'|'F', durationSec:<int sec>, weight:<kg|''>, done:<bool> }` (`reps` absent/untouched). Timer state on the set: `timerStartedAt` (ms, number ⇒ running) and `targetSec` (number|null) and `targetVibratedAt` (ms, once per run). All optional, no migration; `saveActiveSession` persists exercises by reference so a running timestamp lands in localStorage + the IndexedDB mirror with zero extra wiring, and `restoreDraftToActive` deep-loads it → "keeps counting from its real start". Old sets/backups/`finish`d history without `durationSec` simply show `—`; nothing is normalized in a way that rewrites stored data.

**1. Row + timer.** New helpers `isDurationEx(ex)`, `parseDurationInput('1:05'|'65')→65`, `formatDurationClock(65)→'1:05'`, `getDurationError(sec)`, `setElapsedSec(set,nowMs)`, `startSetTimer(exIdx,sIdx)`, `stopSetTimer(exIdx,sIdx)`, `runningSetTimer()`, `stopAllSetTimers()`, `paintRunningSetClocks()`. `renderActiveWorkout` branches per exercise type: header `SET|PREVIOUS|TIME|…|✓`, col 3 = time text input (`updateSetDuration`/`handleSetDurationChange`, model + in-place paint, **never** a rebuild — same rule as `updateSetVal`/`handleSetFieldChange`), col 4 = `▶ Start` / `■ Stop` (72×44 px, inside the existing 412 px grid). Start → `stopAllSetTimers()` first (only one running), then `timerStartedAt=Date.now()`, `targetVibratedAt` cleared, `saveActiveSession()`. Stop → `durationSec = max(1, round(elapsed))`, drops `timerStartedAt`, ticks the set, `startRestTimer(getExerciseRestSec())` via the normal `toggleSetDone` tail (rest timer stays separate). A 1 s ticker (`paintRunningSetClocks`, started in `openWorkoutDrawer`/`restoreDraftToActive`, cleared in `cleanupActiveWorkout` plus the existing `visibilitychange` handler) rewrites only `#set-time-e-s` text.

**2. Target.** Routine items gain `targetDurationSec` (1..86400|null) in `normalizeRoutineItem`; `doStartRoutineWorkout` copies it to each set as `targetSec`; the row shows `target 60 s`. When `elapsed >= targetSec`: clock turns green (`var(--success)`) and `navigator.vibrate(200)` fires **once per run** (`targetVibratedAt`; guarded with `typeof navigator.vibrate === 'function'`), counting continues.

**3. Validation.** `isSetTickable(s, exType)` gains an optional 2nd arg (1-arg calls behave exactly as today): duration ⇒ valid `durationSec` (int ≥1) and weight `''` or valid kg. Callers (`toggleSetDone`, `countDoneValidSets`, `finishReviewTickAll`, `doFinishSave`) pass the exercise type. Duration rows also accept the hand-typed time, so ✓ works with no timer at all.

**4. Save / history.** `doFinishSave` and the routine-update map branch: duration keeps `durationSec` (+ `weight` only when non-empty), drops `reps`, `timerStartedAt`, `targetSec`, `targetVibratedAt` (explicit per-set pick). `scoreHistExercises`/`getBest1RM` skip duration exercises for 1RM and volume (so no fabricated PR from a weighted carry) but still count their sets. `renderHistDetail`, `renderHistory`, and `saveHistEdit` get duration branches (show/keep the time, don't print `undefined` reps, don't zero the time on save).

**5. Previous.** `getPreviousSet` returns `durationSec` too; the row's PREVIOUS and `copyPreviousIntoSet`/`doStartHistWorkout` use the last time (`1:05`).

**6. Progress/records.** New `durationCountingSets(sets)` (non-warm-up, `durationSec ≥ 1`) feeds additive fields: `exerciseRecords` gains `longestHold` (+ existing `heaviestWeight` only from real kg on weighted duration) and is forced empty for `bestE1RM`/`bestSetVolume`/`bestSessionVolume`/`mostRepsInSet`/`repRecords`; `exerciseSessions`/`exerciseSeries` gain `longestHold`/`totalTime`; `renderExerciseProgress` metric buttons/records/timeline show times; `renderProfileRecords` includes duration work (`kg · 1:05` for farmer carry, `1:05` otherwise). `metricCountingSets` itself is untouched.

**7. Routine editor.** `renderRoutineBuilderList` shows `target sec` (input) instead of reps for duration items via `updateBuilderDuration`.
